# Мои цели на семестр

1. Научиться уверенно работать с Git в терминале: ветвление, merge, rebase, разрешение конфликтов — без опоры на GUI.
2. Освоить Docker: собирать образы, писать Dockerfile и docker-compose для собственных проектов.
3. Настроить свой первый CI/CD-пайплайн на GitHub Actions (автотесты + деплой) для пет-проекта.
