# VS Code vs терминал: заметки

Удобно в VS Code:
1. Наглядный diff по файлам прямо в панели Source Control — видно построчные изменения без запуска `git diff`.
2. Коммит через UI: ввёл сообщение, нажал ✓ — быстрее для мелких правок.
3. Визуальный редактор конфликтов при merge — конфликтующие блоки подсвечены, можно принять решение в один клик.

Удобнее в терминале:
- Сложные операции вроде `git rebase -i`, `cherry-pick` — в IDE они либо скрыты, либо неудобны, а в терминале полный контроль над каждым шагом.
